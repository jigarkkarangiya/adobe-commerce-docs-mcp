---
description: Troubleshoot Adobe Commerce / Magento issues using Knowledge Base
---

Use the `search_adobe_commerce_docs` MCP tool with the section filter set to `commerce-knowledge-base` to search for known issues and solutions related to the user's problem. Fetch the relevant page(s) using `get_doc_content`. Provide the known cause, solution steps, and any workarounds. Cite the source URL(s).
